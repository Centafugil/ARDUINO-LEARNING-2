#PIR (Passive infrared) Sensor


#Descrition
 - Pir sensor uses infrared to identify movement
 - It uses heat signature to identify
 - The dome aboves helps it to break down the surroundings in zones
 - And any change between the zones is considerd an Movement


#Specifications:
 - Input voltage : 5v to 20v
 - Output Signal : digital (0 and 1)
 - Pin configuration : 1. power 2. signal 3. ground
