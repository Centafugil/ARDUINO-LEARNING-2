#PIR (Passive infrared) Sensor

*Based on model number HW416 B*


#Descrition
 - Pir sensor detects changes in infrared
 - It uses infrared radiation emitted by objects to identify motion
 - The dome(fresnel lens) aboves helps it to break down the surroundings in zones
 - And any change between the zones is considerd an Movement
 - Two probes which is used to adjust senstivity and range

#Specifications:
 - Input voltage : 5v to 20v
 - Output Signal : digital (0 and 1)
 - Pin configuration : 1. VCC 2. OUT 3. GND
